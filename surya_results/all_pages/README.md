# Surya OCR results

Completed all 68 Chanda Mama scans on 9 October 2026 with Surya OCR 0.22.1, surya-ocr-2 GGUF, llama.cpp b11429 CUDA 12.8 and NVIDIA RTX 2070 SUPER. One page is checkpointed after each inference.

- [Browse the index](index.html)
- [Raw results JSON](results.json): page blocks, HTML text, polygons, confidence and reading order.
- [Combined plain text](combined_transcription.txt)
- Individual transcriptions: `text/Chanda_Mama_01.txt` through `text/Chanda_Mama_68.txt`.

Coverage and JSON structure verified for all 68 input scans; no block error flags were reported. Machine text has not been proofread. Empty or skipped picture blocks do not imply a missing scan. The text files follow Surya reading order and omit HTML tags.
